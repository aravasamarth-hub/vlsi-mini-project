### 5.3 Technical Resolution: Why Does Unconstrained STA Report RCA Faster Than CSKA?
In unconstrained Static Timing Analysis (without functional vector sensitization or `set_case_analysis` constraints), OpenSTA computes the single mathematically worst-case topological path through the circuit graph.

1. **Topological False Path in CSKA:**
   - In CSKA, each 4-bit block has a multiplexer whose `A0` input is fed by the full adder ripple carry out.
   - The longest topological path through the graph enters `A0` on Block 0, ripples into Block 1, enters `A0` on Block 1, ripples into Block 2, enters `A0` on Block 2, ripples into Block 3, and enters `A0` on Block 3.
   - Consequently, unconstrained OpenSTA traces **all 16 Full Adders PLUS all 4 Multiplexers in series** (22 logic stages).
   - In physical silicon, this path is a **topological false path**: a carry cannot simultaneously ripple through all 4 full adders in all 4 blocks in a single continuous propagation chain. If all group-propagate conditions are met, the carry skips via `A1` ($0.19\text{ ns}$ delay) rather than rippling through the full adders ($0.88\text{ ns}$ delay).
2. **Comparison with RCA:**
   - RCA has no skip multiplexers; its full ripple path contains exactly 16 Full Adders (18 logic stages).
   - In unconstrained STA, CSKA delay equals the full 16-bit RCA ripple delay plus the insertion delay of 4 multiplexers ($4 \times \sim 0.20\text{ ns} \approx 0.8\text{–}1.0\text{ ns}$).
   - **Academic Precision Rule:** OpenSTA unconstrained post-route timing correctly reports the topological graph delay ($4.38\text{ ns}$ for HS CSKA vs $3.81\text{ ns}$ for HS RCA; $7.67\text{ ns}$ for HD CSKA vs $6.72\text{ ns}$ for HD RCA). The CSKA speed advantage only manifests under sensitizable vector analysis where skip paths bypass ripple chains.

   - Status: **PARTIALLY VERIFIED** (Documented topological artifact).
